# OpenGame 0.5.8 · 内测版 / Prerelease

在 Apple Silicon Mac 上安装和运行 Windows 游戏的独立完整包。此构建要求 **macOS 26.0 或更新版本及 Rosetta**；不支持 Intel Mac。运行核心的实际最低系统版本已与应用元数据、双语 README 对齐。尚未经过 Apple 公证。

## 下载 / Downloads

- 安装包 / Application: `OpenGame-0.5.8-macos-arm64.zip`
- 对应源码 / Corresponding source: `OpenGame-0.5.8-corresponding-source.tar.xz`
- 校验 / Checksums: `SHA256SUMS.txt`

安装包不包含 Steam、游戏、账号、容器或存档。无需安装 CrossOver；不捆绑 CrossOver 专有运行库、D3DMetal 或专有配方。

## 改进 / Changes

- Steam 游戏自动发现覆盖默认库和容器盘符可访问的其他库；提供刷新、安装/下载/更新/不可用/运行状态，保留自定义名称、参数和图标。
- 入口通过对应容器 Steam 的 AppID 启动，等待客户端准备完成并保护重复请求；下载中或无效入口提供明确错误。
- 官方 Steam 更新器退出后有界恢复一次；兼容处理覆盖两种 CEF 目录。连接和进程检查限定于本容器。
- 中文 fallback 链接本机已有字体，不复制或分发 Apple 字体。
- 两套独立 Wine FOSS 核心修正目录枚举 BOOLEAN ABI，并保留 Darwin IP_RECVTOS 修复。
- MSync、DXMT 帧率、高分辨率与实验性 NVAPI/NGX 选项随容器配置保存；不可用能力禁用。D3DMetal 未实现。
- 运行中的按钮改为“切换到游戏”，无法直接激活窗口时提示手动切换。界面明确提醒退出 OpenGame 会关闭游戏与 Steam，应先保存。

Automatic Steam discovery supports mapped libraries, preserves custom entries, and shows installation and launch states. Steam launches remain scoped to the selected container and AppID. Official updater recovery is bounded; CJK fallback uses existing host fonts. Both independent Wine FOSS cores include directory BOOLEAN and Darwin IP_RECVTOS fixes. The UI explains that quitting closes games and Steam.

## 验证范围 / Validation

- 六组源码回归通过；原生 UI 实测游戏列表、中文、刷新、启动状态及重复请求保护。
- 发布候选签名严格校验及运行库审计通过：569 个 Mach-O 文件，无私人运行状态或非系统绝对依赖。所有架构最低系统要求扫描最高为 26.0。
- 隔离全新数据目录验证运行库、字体、配方、容器创建、归档导出恢复与 H.264 OpenH264→VideoToolbox 管线；Wine 后端 D3D12 device 及 64/32 位 Wine GStreamer 模块探针通过。
- 本机用户确认 Steam 登录、游戏下载、How to Fish 存档游玩和电脑扬声器音频；入口启动及原生 UI 状态由维护测试独立验证。
- 未完成第二台全新 Mac 的完整游玩验收、三轮游戏内完整复测或同场景 CrossOver 性能对比。没有平均 FPS、1% low 或尾延迟结论，也不宣称全面 1:1。
- 标准 Steam 模式、覆盖层、游戏 DLSS 图像/帧生成、DX12 游戏、广泛视频/联机/语音及所有音频设备兼容性未全面验证。AirPods 场景音频问题未确诊，本轮不应用输入设备覆盖。

Six source test groups, native library UI and duplicate-launch checks, strict signing, runtime audit, isolated installation/archive tests, H.264 pipeline, Wine D3D12 device and Wine GStreamer probes passed. User feedback confirms this game's save gameplay and built-in speaker audio. Three complete gameplay cycles, a second clean Mac, matched CrossOver performance and broad game/device compatibility remain unverified.
